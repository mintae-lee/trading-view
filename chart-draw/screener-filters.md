# 트레이딩뷰 스크리너 필터 (미국주식 · 수동 검색)

이 폴더의 5개 기법이 공유하는 전제 — **"역배열 바닥권에서 반등 초입"** — 을
트레이딩뷰 **일반 스크리너**(Pine Screener 아님)로 예비 필터링하는 세팅.
한국어판 UI 기준 필드명.

---

## 전제

- **스크리너는 후보 추리기 전용.** 매집봉 → 파란선 돌파 → 눌림목 같은 시퀀스는
  못 거른다. 스크리너로 20~40종목 추린 뒤 차트에 Pine 지표를 얹어 눈으로 확정한다.
- **스크리너엔 112/224/448 이 없다.** 5·10·20·30·50·100·200 만 제공되므로
  **50 / 100 / 200 으로 근사**한다. 비율(1:2:4)이 같아 "역배열 모양"은 살아있지만
  절대 기간이 짧으니, 최종 판단은 차트에서 112/224/448 로 한다.
  ([README.md](../README.md) "이평선 기간에 대한 메모" 참고 — 미국 50일선은
  2.4개월짜리로 이 기법의 중기선(5.5개월)과 역할이 다르다. 통과 = 후보일 뿐.)
- SMA·EMA 둘 다 필터 있음. **이평때리기(MaHit)만 EMA**, 나머지는 SMA.

---

## STEP 1 — 유니버스 / 유동성 (항상 공통)

| 필터 | 값 | 이유 |
|---|---|---|
| 거래소 | NASDAQ, NYSE, NYSE ARCA/AMEX | 미국 주식 |
| 유형 | 보통주 (Common Stock) | ETF·우선주 노이즈 제거 |
| 시가총액 | 20억 달러 이상 | 세력 매집 논리가 성립하는 규모 |
| 평균 거래량 (90일) | 100만 주 이상 | 스윙 진입·손절 슬리피지 |
| 종가 | 10달러 이상 | 동전주 제외 |

> 소형주까지 공격적으로 보려면 시총 5억, 거래량 50만으로 완화.

## STEP 2 — 역배열 바닥권 (기법 공통 전제)

| 필터 | 값 | 대응 개념 |
|---|---|---|
| 종가 < 단순이동평균 (200) | — | 장기선(224) 아래 = 바닥권 |
| 성과 (1년) | 0% 미만 (엄격히 −15% 이하) | "오래 내렸다" |
| 성과 (6개월) | 0% 미만 | 하락이 최근까지 이어짐 |
| 52주 고점 대비 변동률 | −30% 이하 | 낙폭과대 |
| 단순이동평균(50) < 단순이동평균(200) | — | 역배열 정렬 직접 확인 |

> **이평 vs 이평 비교는 트레이딩뷰 스크리너에서 실제로 된다.** `단순 이동 평균` 필터를
> 넣고 → 매뉴얼 셋업 → 기간 50 → 조건 `미만` → 타겟을 `값` 대신 `단순 이동 평균` 200 으로.

여기서 3갈래로 나뉜다 — **하나만 골라 STEP 2에 추가**한다.

STEP 2에서 `종가 < SMA(200)` 유지하고 추가:

| 필터 | 값 | 이유 |
|---|---|---|
| 종가 > **지수**이동평균 (50) | — | 112일선 "안착" 근사 (EMA) |
| 종가 < 지수이동평균 (200) | — | 아직 장기선 아래 = "공짜 라인" 구간 |
| 52주 저점 대비 변동률 | +2% ~ +25% | 바닥 찍고 막 올라온 상태 |
| 상대 거래량 | 1.5 이상 | 세력 개입 거래량 |
| 성과 (1개월) | +3% 이상 | 돌아서는 중 |

대응 스크립트: `MaHit.pine`, `pending/Reverse112.pine`

## 실전 스크린 — 밥그릇 ∩ 역매공파 공통 (브라우저에서 테스트함)

갈래 B(밥그릇)와 역매공파26_112 를 **한 스크린으로** 돌리는 세팅. 두 기법의 교집합은
**"장기선(224) 아래 + 역배열 + 최근 3개월 횡보(바닥 다지기) + RSI 중립권"** 이다.
갈래 B 의 "돌파 당일" 조건(1주 성과·상대거래량 급증)은 빼고 **관심리스트**로 만든 것 —
돌파·골든크로스·매집봉은 차트에서 확인한다.

| 필터 (한국어판) | 값 | 두 기법 공통 근거 |
|---|---|---|
| 가격 < 단순이동평균 (200) | — | 밥그릇: 224 아래 / 역매공파: 바닥권 |
| 단순이동평균 (50) < 단순이동평균 (200) | — | 역매공파: 역배열 / 밥그릇: 하락 후 정렬 |
| 시가총액 | 2B ~ 500B USD | 유동성·세력 개입 규모 |
| 평균 거래량 (10일) | > 1M | 유동성 |
| 성과 (YTD) | < −20% | 올해 크게 하락 |
| 성과 (6개월) | < −12% | 하락 지속 |
| 성과 (3개월) | −10% ~ +10% | 밥그릇: 좁은 횡보 / 역매공파: 지지라인·매집 구간 |
| RSI (14) | 35 ~ 62 | 바닥권, 아직 과열 아님 |

→ 2026-09 기준 약 33종목. 결과가 너무 많으면 3개월 성과를 ±8%, 6개월을 −20% 로 조인다.
너무 적으면 반대로 3개월 ±15%, 6개월 −8% 로 푼다.

### 차트에서 기법 판별

| | 확인 포인트 | 스크립트 |
|---|---|---|
| **밥그릇** | 224선 아래 좁은 횡보 → 5·20 골든크로스 → 224선 근접(±2%) | `BowlNo3_256.pine` |
| **역매공파** | 112<224<448 확인 + 매집봉(거래량 급증) + 파란 점선 돌파 + 눌림목 양봉 | `Reverse112-26.pine` |

스크리너가 못 거르는 것 → 차트: 골든크로스, 매집봉 거래량, 파란선, 224 근접, 횡보 폭.

> ADR(예: TCEHY·PDD·HDB·INFY·GRAB)이 섞인다. 미국 본토 종목만 원하면 `유형 = 보통주` 추가.

## 스크리너 운용 팁

- 필터 추가: 하단 `필터 넣기` / 상단 `+` / `Shift + F`. 설정 후 좌상단 `저장`.
- 갈래별로 필터셋을 저장해두고 번갈아 실행 (또는 위 "공통 스크린" 하나로)
- 결과는 성과(6개월) 오름차순 정렬 → 가장 많이 빠진 것부터 차트 확인
- 차트에서 확정: 해당 `.pine` 붙여넣고 상태 패널이 "③ / 2단계 / 3/3" 인지,
  급락이 갭(실적 쇼크)인지 확인

---

## 주의

- 50/200 은 스크리너 근사일 뿐. 매수 판단은 차트에서 112/224/448 + Pine 지표로.
- 실적 시즌 가이던스 쇼크로 빠진 종목이 섞인다 → 차트에서 갭 여부 확인.
- 필드명은 트레이딩뷰 로케일/버전에 따라 다를 수 있다. "성과"는 Performance,
  "상대 거래량"은 Relative Volume, "52주 고점 대비 변동률"은 52-Week High Change %.
